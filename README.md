# building-cross-platform-apps-with-net-maui-blazor-hybrid
This repo contains the sample code for a .NET MAUI Blazor Hybrid app with a Blazor Web App, used as a demo in .NET MAUI Day 2026 talk. It demonstrates shared UI via a Razor Class Library, code reuse across native and browser targets, multi-device rendering, and platform-specific services through DI.
